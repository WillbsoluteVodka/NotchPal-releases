# NotchPal

住在 Mac 刘海里的像素宠物和小工具。

这个仓库只放安装包，App 的自动更新也从这里下载。

## 安装

1. 到 [最新版本](https://github.com/WillbsoluteVodka/NotchPal-releases/releases/latest) 下载 `NotchPal-x.y.z.dmg`。
2. 打开 DMG，把 NotchPal 拖进「应用程序」。
3. 从「应用程序」打开 NotchPal。

需要 macOS 13 或更新的系统。App 已经过 Apple 公证，不会出现「无法验证开发者」的提示。

## 更新

装好之后不用再来这里：NotchPal 打开时和之后每两个小时会检查一次新版本，也可以在设置 → 预设页最下面点「检查更新」。
有新版本时会弹出提示，点安装后 App 会自动退出、更新、再打开，登录状态和设置都会保留。
